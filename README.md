## Архитектура проекта
Проект строго разделен на 4 слоя в соответствии с принципами **Clean Architecture** и **SOLID** (в первую очередь *Single Responsibility* и *Dependency Inversion*).

1. **`data_layer.py`**: Содержит чистые сущности предметной области (`Book`, `Reader`). Не зависит от других слоев.
2. **`repository.py`**: Реализует CRUD операции. Содержит абстрактный класс `Repository` (интерфейс) и его конкретную реализацию `MemoryRepository` (хранение в оперативной памяти). 
3. **`service.py`**: Инкапсулирует бизнес-логику (выдача книг, валидация). **Важно:** сервис зависит только от абстракции `Repository`, а не от конкретной реализации `MemoryRepository`.
4. **`main.py` (Точка входа / UI)**: Консольное меню, которое собирает зависимости (Dependency Injection) и обрабатывает ввод/вывод, перехватывая ошибки сервисного слоя.
